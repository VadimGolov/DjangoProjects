## Описание проекта Размышления от типографике:
### Пример разработки на фреймворке Django.

---
### Описание:

Это очень простой, тестовый проект. Идея проекта изначально заключалась в
приведении полного текста Lorem Ipsum И исследования возможностей современной
нейросети для его философского описания. Однако потом появилась мысль 
дополнить текст информацией о русских и английских панграммах.

### Структура:

Данный проект имеет стандартную структуру django-проекта. В главной папке проекта
web-project, находится приложение main. В файле views.py сосредоточена простенькая логика.
Основой всего проекта являются HTML-файлы, содержащие всю информацию. Они находятся в
`web-project/main/templates/main/`, CCS расположена в `web-project/main/static/main/css/`
такая структура была применена для возможного расширения, в том случае если в проекте
появятся новые приложения.

### Технологии:

- Веб-приложение на Django;
- Серверная часть на Python с использованием Django.

HTML-макеты подготовлены с помощью Bootstrap и CSS. Затем были разделены для шаблонизатора Jinja,
который уже собирает их в нужном виде. Изменяет вид активности страницы, подставляет url-остальных страниц.
Основой служит файл **layout.html** к которому подключены **Bootsrap** и **CSS**

### Запуск:

Для того чтобы не давать в терминале команды. Был создан простой тестовый файл start.py, который осуществляет
запуск проекта.
